# INTERNAL_CONSULT reviewer roles

- ARCHITECT: inspect boundaries, coupling, reversibility and simpler alternatives.
- EVIDENCE: verify claims against authoritative files, tests, logs, commits and exact state.
- RED_TEAM: search for a concrete reproducible counterexample; do not optimize for agreement.
- TEST_ORACLE: define the smallest decisive falsification test and inspect whether it actually ran.

All first-round roles are independent and read-only. They receive the same factual consultation bundle and no peer conclusions.
