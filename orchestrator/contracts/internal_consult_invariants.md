# INTERNAL_CONSULT invariants

1. Native Hermes delegation is reused; no second agent runtime is introduced.
2. Consultation children are read-only.
3. First-round reviews are context-independent from peer conclusions.
4. A reproducible counterexample outranks consensus.
5. Reversible LOW/MEDIUM work may auto-proceed only after quorum.
6. Critical, high-risk, irreversible or persistently ambiguous gates go to ASTRA.
7. Only genuine human-authority gates go to DAVID.
8. GitHub transport identity is not decision identity.
9. Marker text alone never authenticates a decision actor.
10. No new API credential, provider switch, gateway edit or channel edit is required.
