# Bootstrap Checklist

## Phase A — private repository
- Create private `panorama-mission-control`.
- Initialize one Obsidian vault at repository root.
- Add the standard folder tree and project templates.

## Phase B — inventory
- Inventory both computers and all discovered vault candidates read-only.
- Record counts, roots, project affiliation, duplicates and unknowns.
- Publish only sanitized inventory summaries outside the private repo.

## Phase C — consolidation
- Create nodes for IA-VISION, SUINI, TrafficLab Control and Panorama first.
- Import confirmed Markdown knowledge.
- Add pointer records for external/heavy files.
- Preserve originals until acceptance.

## Phase D — multi-PC
- Bootstrap PC-A from private remote.
- Bootstrap PC-B from the same remote.
- Prove edit/publish/sync roundtrip.
- Prove intentional conflict handling.

## Phase E — agents
- Hermes ORCH can maintain indexes and inventories.
- Product agents operate only in their ownership node.
- Astra audits cross-project consistency.
- Every automated note change remains attributable through Git history.
